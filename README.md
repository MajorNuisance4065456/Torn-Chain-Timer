Torn Chain Timer, a single stand alone exe file.
1. Download
2. Open file
3. Enter API key, this is never stored
4. Press enter
5. Enjoy the least restrictive way to chain.
6. (hint) The target on the left will bring you to your targets list.
7. Help fund better versions 


 API is called every 30 seconds, timer may run 30sec low max before it catches up to the chain timer reup after an attack.
